# 🎂 Shree's Special Birthday Website 🎉

A romantic, aesthetic, and mobile-friendly birthday website built for **Shree**.

---

## ✨ Key Features

1. **🎵 Automatic "Tu Hai Kahan" Romantic Song**:
   - Webpage open hoto ch ki song automatic play hoto!
   - Built-in Web Audio romantic synthesizer fallback so music never fails!
2. **📱 100% Mobile Responsive**:
   - Touch drag photo ring, fluid typography, mobile glassmorphism cards.
3. **🖼️ 3D Circular Auto-Scrolling Photo Gallery ("Round Madhe Auto Scroll")**:
   - Continuous 3D auto-rotating photo cylinder ring.
4. **🎨 4 Live Themes (Top-Right Toolbar)**:
   - Velvet Midnight, Dreamy Pink Romance, Golden Sunset Love, Neon Moonlight.
5. **🎂 Interactive Birthday Cake & Blowable Candles**:
   - Tap cake to blow out candles & trigger confetti explosions.
6. **🎁 Secret Gift Box & Handwritten Love Letter Modal**.

---

## 🎵 How to add your custom "Tu Hai Kahan" MP3 file:

1. Create a folder named `music` inside the `shree birthday` folder.
2. Put your MP3 audio file inside it as `tu_hai_kahan.mp3` (e.g. `music/tu_hai_kahan.mp3`).
3. Website automatically picks up `music/tu_hai_kahan.mp3` and plays it continuously!

## 🚀 Deployment Instructions for Netlify (Quick & Free):

### Option A: Netlify Drop (Easiest - 30 Seconds)
1. Go to **[app.netlify.com/drop](https://app.netlify.com/drop)** in your web browser.
2. Drag and drop the whole `shree birthday` folder into the Netlify box on the screen.
3. Done! Netlify will immediately give you a live website link (e.g. `https://shree-birthday.netlify.app`).

### Option B: Netlify CLI
1. Open terminal in this folder:
   ```bash
   npx netlify-cli deploy --prod
   ```
2. Follow the prompt to publish the `.` directory.
